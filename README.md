# Guitar Coach

A beginner guitar trainer that runs in the browser. It shows you a note (string and fret), listens through the microphone, and lights up green when you play it right.

- **Tuner**
- **Lessons**: open strings, first fretted notes, a scale, note quizzes
- **Songs**: simple melodies, plus a few Petra pieces (from Songsterr community transcriptions)

Open it here: https://mkcan1973.github.io/guitar-coach/

To run it locally, double-click `start.bat`. It serves the page on http://localhost:8765, which the browser needs before it will allow the microphone.
